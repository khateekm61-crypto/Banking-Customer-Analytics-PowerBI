# Banking Customer Analytics Dashboard

## Project Overview

This is a Banking Customer Analytics Dashboard project built using Power BI, DAX and Python.

The main purpose of this project is to analyze banking customer data, loans, deposits, account balances and financial KPIs.

Python is used for Exploratory Data Analysis (EDA), while Power BI is used to create an interactive dashboard.

## Project Objective

- Analyze banking customer data
- Understand loan and deposit information
- Analyze customer and account metrics
- Create important business KPIs
- Compare banking products and customer segments
- Build an interactive Power BI dashboard
- Generate meaningful business insights

## Dataset

The dataset contains 3,000 banking clients and 25 columns.

It includes information related to:

- Customer details
- Gender
- Nationality
- Occupation
- Banking relationship
- Estimated income
- Bank loans
- Business lending
- Bank deposits
- Savings accounts
- Checking accounts
- Foreign currency accounts
- Credit card balance
- Properties
- Risk weighting

## Python EDA

Python was used for Exploratory Data Analysis.

The EDA includes:

- Dataset inspection
- Rows and columns analysis
- Data types

- Duplicate checking
- Categorical analysis
- Numerical analysis
- Data visualization
- Correlation analysis

The Power BI dashboard contains the following pages:

The dashboard provides interactive analysis using filters, KPIs, charts and customer-level drill-through analysis.
